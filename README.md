One fresh one-line joke about office life, written by a small deterministic
Python program for make.fun's "One-Line Office Joke: 24-Hour Sprint" bounty.
`main.py` writes the joke to `/output/entry.txt`: a single line, 135
characters, no network, no randomness — the same text on every run.

## Run it

```sh
python3 main.py
```

The joke lands in `/output/entry.txt` (override with `OUTPUT_FILE`).
